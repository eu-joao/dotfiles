# Instruções para agentes

- Não precisa fazer pull requests, faça commit direto na main.
- A estrutura de diretórios e arquivos segue o padrão do Chezmoi.
- Mantenha comentários simples em bloco para explicar detalhes específicos do código, evite os inline para não ficar visualmente poluído demais.
- Os commits podem ser feitos no iperativo sem acentuação ou caracteres especiais, não precisar seguir conventional commits.
- Verifique a pasta de spec como referência das configurações dos programas.
